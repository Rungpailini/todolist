# TeamFlow - ระบบจัดการงานและติดตามภาพรวมทีม (Team Todo & Kanban)

ระบบ Web Application สำหรับติดตามงานของทีม (Team Todo List & Kanban Board) ที่ออกแบบให้ใช้งานง่าย เห็นภาพรวมของทั้งทีมได้อย่างชัดเจน พร้อมระบบสลับมุมมองระหว่าง **หัวหน้างาน** และ **ทีมงานแต่ละคน** โดยไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์ใดๆ

## ✨ ฟังก์ชันหลักที่พัฒนาตามความต้องการ

### 1. หน้าหัวหน้างาน (Manager Overview)
- **Dashboard สรุปภาพรวม**:
  - การ์ดสถิติงานทั้งหมด (Total Tasks), กำลังดำเนินการ (In Progress), เสร็จสิ้น (Completed พร้อม % อัตราความสำเร็จ), งานที่ใกล้หรือเลยกำหนดส่ง (Overdue / Due Soon)
- **ภาระงานของลูกทีมแต่ละคน (Team Workload)**:
  - แสดงการ์ดของสมาชิกแต่ละคน แสดงจำนวนงาน ความคืบหน้า และสามารถคลิกที่การ์ดเพื่อกระโดดไปดูบอร์ดของคนนั้นได้ทันที
- **บอร์ดรวมของทั้งทีม (Team Kanban)**:
  - หัวหน้าสามารถดูการ์ดงานของทุกคน พร้อมเห็น Avatar และชื่อผู้รับผิดชอบบนทุกการ์ด
  - ตัวกรองอัจฉริยะ: กรองเฉพาะสมาชิกที่ต้องการ, กรองตามระดับความสำคัญ, กรองเฉพาะงานที่เลยกำหนดส่ง, และช่องค้นหาแบบเรียลไทม์
- **การมอบหมายงาน (Assign)**:
  - หัวหน้าสามารถกดปุ่ม "สร้างงานใหม่" และเลือกมอบหมายให้ลูกทีมคนใดก็ได้

---

### 2. หน้าของทีมงานแต่ละคน (Personal Member View)
- สลับมุมมองได้ง่ายๆ ที่แถบเมนูด้านบนผ่าน **Dropdown "สลับมุมมอง"**
- เมื่อเลือกเป็นสมาชิกคนใดคนหนึ่ง (เช่น สมชาย, สมศรี, อานนท์, กัญญา):
  - ระบบจะคัดกรองเฉพาะงานของคนนั้นมาแสดง
  - หน้าจอเป็น **Kanban Board** เต็มรูปแบบ 4 สถานะ:
    1. **รอดำเนินการ (To Do)**
    2. **กำลังทำ (In Progress)**
    3. **รอตรวจ (Review)**
    4. **เสร็จสิ้น (Done)**
- **ลากและวาง (Drag & Drop)**:
  - สามารถคลิกลากการ์ดย้ายข้ามคอลัมน์เพื่อเปลี่ยนสถานะงานได้ทันที
  - มีปุ่มลูกศร `<` และ `>` บนการ์ดสำหรับการเลื่อนสถานะด้วยการคลิก (เหมาะกับอุปกรณ์จอสัมผัสหรือมือถือ)
- สมาชิกสามารถสร้างงานส่วนตัวของตัวเอง หรือแก้ไข/ลบงานที่ตนเองรับผิดชอบได้

---

### 3. ข้อมูลในแต่ละงาน (Task Fields)
ตรงตามที่ระบุในข้อกำหนด พร้อมฟังก์ชันเสริมเพื่อประสิทธิภาพการทำงาน:
- **ชื่องาน (Task Title)**
- **รายละเอียดงาน (Description)**
- **วันที่สร้าง / วันที่เริ่ม (Start Date)**
- **กำหนดส่ง (Deadline)**:
  - มีระบบคำนวณและแจ้งเตือนอัตโนมัติ:
    - 🔴 **เลยกำหนด (Overdue)**: ขึ้นแถบสีแดงกระพริบเตือนและบอกจำนวนวันที่เลยกำหนด
    - 🟠 **ส่งวันนี้ (Due Today)**: ขึ้นแถบเตือนสีส้ม
    - 🟢 **เสร็จสิ้น (Done)**: ขึ้นเครื่องหมายเสร็จสมบูรณ์
- **ผู้รับผิดชอบ (Assignee)**: พร้อม Avatar และชื่อ
- **ระดับความสำคัญ (Priority)**: ด่วนมาก (Urgent), สูง (High), ปานกลาง (Medium), ทั่วไป (Low)
- **สถานะ (Status)**: To Do, In Progress, Review, Done

---

### 4. ระบบจัดการข้อมูลและการสำรองข้อมูล (Data Management)
กดที่ไอคอน **ฟันเฟือง (Settings)** ที่มุมขวาบน จะมีแถบควบคุมข้อมูล:
- **บันทึกอัตโนมัติ (Auto-save)**: บันทึกข้อมูลลงในเบราว์เซอร์ (LocalStorage) ไม่สูญหายเมื่อรีเฟรชหรือปิดหน้าต่าง
- **จัดการรายชื่อสมาชิก (Team Members)**: สามารถเพิ่มสมาชิกใหม่ ระบุชื่อและตำแหน่ง หรือลบสมาชิกได้ตามต้องการ
- **ส่งออก JSON (Export)**: ดาวน์โหลดไฟล์สำรองข้อมูลทั้งหมดของทีมเป็นไฟล์ `.json`
- **นำเข้า JSON (Import)**: นำเข้าไฟล์ข้อมูลเพื่อกู้คืนหรือถ่ายโอนข้อมูลไปยังเครื่องอื่น
- **รีเซ็ตเป็นข้อมูลตัวอย่าง (Reset Demo Data)**: คืนค่าข้อมูลตัวอย่างเพื่อการทดสอบระบบใหม่ได้ตลอดเวลา
